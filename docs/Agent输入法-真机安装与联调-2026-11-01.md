已在本仓库实现并编进这个包的功能：

1. 键盘底排新增 **AI** 键，点开 Agent 面板（提问态 / 回答态）。
2. 面板内可用**同一套中文键盘**输入问题：拼音 → 候选 → 上屏进面板，不污染宿主输入框。
3. 「发送」→ 后端流式（SSE）渲染 DeepSeek 真实回答；生成中可「取消」。
4. 「插入 / 改写」把回答写回宿主输入框；「撤销」回退这次写入（改写会还原被替换的原文）。
5. 密码类输入域自动禁用 AI 面板（不读上下文、不写回）。
6. **面板内可配置后端地址与令牌**（右上「设置」），默认已填好本机局域网地址。
7. 默认存储模式改为 `APP_STORAGE`（应用私有），真机首次安装**不需要**再手动改 prefs。

## 2. 前置条件

- 手机：Android 5.0+（minSdk 21）、arm64-v8a、和电脑在**同一个 Wi-Fi**。
- 电脑：Windows + Python（`python` 在 PATH 上）、`DEEPSEEK_API_KEY` 在 **用户级**环境变量里（`setx DEEPSEEK_API_KEY "sk-..."`，已设过可跳过）。
- 电脑与手机的 Wi-Fi 网络配置文件建议是「专用网络」（Windows 防火墙放行规则默认只对 Private 生效）。

## 3. 第一步：在电脑上启动后端

在**普通可见的 PowerShell 窗口**（不要隐藏窗口启动，否则 Windows 防火墙的允许弹窗不会出现）执行：

```powershell
cd "C:\Users\A'maris\Documents\ChatGPT\agent输入法\project\backend"
powershell -ExecutionPolicy Bypass -File .\run-backend.ps1 -Lan
```

看到 `[run-backend] host=0.0.0.0 port=8787 ...` 即启动成功。若弹出 Windows 防火墙提示，**勾选「专用网络」并点允许**。

如果没弹窗/手机连不上，用**管理员** PowerShell 放行一次：

```powershell
New-NetFirewallRule -DisplayName 'AgentIME Backend 8787' -Direction Inbound -Protocol TCP -LocalPort 8787 -Action Allow -Profile Private
```

查电脑当前 Wi-Fi 地址：

```powershell
(Get-NetIPAddress -AddressFamily IPv4 | Where-Object InterfaceAlias -like '*WLAN*').IPAddress
```

验证后端是否活着（电脑上另一个窗口）：

```powershell
curl.exe --noproxy "*" http://<电脑IP>:8787/healthz
# 期望 {"ok": true}
```

> 备选联调方式（不想开防火墙）：手机用 USB 连电脑并开 USB 调试，执行
> `adb reverse tcp:8787 tcp:8787`，然后把面板里的后端地址改成 `http://127.0.0.1:8787/v1/chat/stream`。

## 5. 第三步：启用输入法

1. 打开「设置」→「系统」→「语言和输入法」→「屏幕键盘」→「管理键盘」。
2. 打开 **Trime (Debug)** 的开关。
3. 返回「屏幕键盘」→ 选「Trime (Debug)」为默认输入法。
4. 随便点一个输入框（如「信息」里新建短信），键盘应弹出。

首次弹出可能慢 1 秒左右（等 rime 部署完成、主题就绪后自动补建视图，日志 `agentime: creating deferred input view after … ms`）。
如果超过 10 秒仍是空白：收起键盘再点一次输入框；还不行就**重启手机**（应用进程被杀后系统会重新拉起服务，这是已知的 Trime 首次恢复路径）。

判断中文引擎就绪：键盘空格键标签显示「朙月拼音」、底部工具条显示「中文」。看到这个就说明 `librime` 与词库部署正常，可以打拼音。

## 6. 第四步：使用 Agent 面板

1. 点键盘**底排的「AI」键**（在「朙月拼音」和「，」之间）→ 面板出现在键盘上方。
2. 直接用中文键盘打拼音，候选框选字 → 文字进入面板的「问题」行（**不会**写进上面 App 的输入框）。
3. 按 **Enter** 或点「发送」→ 状态变「正在请求…」，回答逐字流式出现（生成中右侧出现「取消」）。
4. 点「插入」→ 回答写回当前输入框；若打开面板前框里有选中文本，按钮显示「改写」，点它替换选区。
5. 点「撤销」→ 回退上一次写入（改写场景会还原原文）。
6. 点「关闭」或再点 AI 键收起面板。

密码框/密码类输入域里打开 AI：面板会显示「敏感输入：已禁用 AI 面板」，按钮置灰，键盘输入也不进面板（不会读取、不会写回）。

## 7. 第五步：改后端地址 / 令牌（如果需要）

1. 面板右上「**设置**」→ 显示「后端地址」「客户端令牌」两行，第一行默认选中（黑框）。
2. 文字形如 `http://172.24.217.222:8787/v1/chat/stream`。若你的电脑 Wi-Fi IP 不是这个：
   - 点要改的那一行选中它；
   - **此时键盘输入直通 ASCII**（不经拼音）：字母/数字/`.`/`/`/`:` 直接追加，退格删字符；
   - 改完按 **Enter** 或点「保存」（状态显示「已保存后端设置」）。
3. 点「返回问答」放弃修改。
4. 令牌必须与电脑上 `run-backend.ps1` 的 `CLIENT_TOKEN` 一致（默认 `dev-agentime-token`）。

> 小提示：地址改了之后如果还想用 `adb reverse`，把地址设成 `http://127.0.0.1:8787/v1/chat/stream`。

## 8. 联调排查表

| 现象 | 可能原因 | 处理 |
| --- | --- | --- |
| 面板状态「失败：后端没有启动/地址不对」 | 后端没起、手机不在同一 Wi-Fi、地址写错、防火墙拦了 | 电脑 `curl --noproxy "*" http://<IP>:8787/healthz`；确认手机连的是同一 Wi-Fi；放行防火墙 |
| 面板状态「失败：客户端令牌无效」 | 面板令牌 ≠ 后端 `CLIENT_TOKEN` | 面板「设置」改成一致后保存 |
| 面板状态「失败：今天额度已用完」 | 后端 `DAILY_QUOTA=50` 用满 | 重启后端进程或调 `DAILY_QUOTA` |
| 面板状态「失败：上游超时 / 上游模型报错」 | DeepSeek 侧网络或 Key 问题 | 电脑上 `curl --noproxy "*" https://api.deepseek.com/v1/chat/completions ...` 直连测试 |
| 键盘空白一直不出 | 首次部署 + 主题未就绪 | 收回再点输入框；重启手机 |
| 空格键显示 `.default`、打不出中文 | rime 部署未完成 | 等 5–10 秒；仍不行则「设置 → Trime 设置」里重新部署，或清应用数据重装 |
| 面板打开后点按钮没反应 | 触摸区未覆盖面板 | 本版已修（`onComputeInsets` 用 `TOUCHABLE_INSETS_REGION`）；若遇到请记录系统版本 |
| 插入/改写位置不对 | 宿主 App 使用了自定义输入框 | 优先在微信/短信/备忘录测试；记录 App 名与版本 |

## 9. 已知限制（本包）

1. 只发 `arm64-v8a`；x86 模拟器包是 `com.osfans.trime-*-x86_64-debug.apk`（内部验证用）。
2. debug 签名，不能覆盖安装到应用商店版 Trime（包名不同可共存）。
3. 回答依赖电脑上的后端进程；电脑关机/睡眠后不可用；电脑关机后不要指望它。
4. `DEEPSEEK_API_KEY` 只放在电脑环境变量里，APK 内不含 Key。
5. 面板高度固定（回答区 140dp，长回答可滚动）；九宫格/T9 键盘尚未做。
6. 撤销按「长度 + 快照」回退，若期间手动改过文本可能不精确。
7. 未做 TalkBack / 大字体适配；横屏未重点验证。
